# Jevson — red-team evidence register

Every evidence tag in `DESIGN.md` and `PLAN.md` resolves here. (The README states no fact that DESIGN does not; it carries no tags.) A tag names **how** a claim was established: a live probe (**P**), a local check run as code (**L**), the vendor's own documentation (**V**), or an external source (**X**). Scripts live in [`scripts/redteam/`](../scripts/redteam/); raw outputs and each round's full reports live in `scripts/redteam/results/<round>/`.

**Conventions**

- Live probes ran against the pinned model `jev-1.13.0` with the team key loaded from a gitignored `.env`. After every round, a search for the key over every script and output returned nothing.
- Rates carry Wilson 95% intervals.
- **Pilot datasets are synthetic and author-written.** They test mechanisms and falsify claims; they do not replace the pre-registered Phase 0 probes, which use real documents.
- Vendor pages were retrieved on 2026-09-29 from <https://docs.typesafe.ai/>. `scripts/redteam/fetch_vendor_docs.sh` re-fetches them; the snapshot is not committed.
