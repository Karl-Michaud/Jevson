Lenovo All In One Desktop Computer

Overview

Lenovo IdeaCentre C50-30 all-in-one desktop computer. This lot is in unused condition.

Specifications

Make: Lenovo

Model: IdeaCentre C50-30

Key Features

23-inch Full HD display with 1920x1080 resolution.

Space-saving all-in-one design combining computer components and monitor into single unit.

Intel Core i3, i5 4th generation, or Pentium processors depending on configuration.

Intel HD Graphics or optional NVIDIA GeForce 820A discrete graphics.

Up to 8GB DDR3L RAM at 1600 MHz.

500GB to 2TB hard disk drive storage.

Windows 10 operating system.

Built-in Wi-Fi and Ethernet connectivity.

Multiple USB ports including USB 3.0 and USB 2.0.

Integrated DVD-RW optical drive.

720p webcam with digital microphone.

Dual built-in stereo speakers.
